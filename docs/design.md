# デザインプラン「ライトステージ」

Web エディタ(`web/`)の見た目の基準です。承認済みのデザイン案「ライトステージ」(Issue #18)を転記しています。トークンの実体は `web/src/styles/tokens.css` にあります。

## 原則

1. **主役はアバター。ステージだけ明るく、道具は暗く沈める** — ビューポートは白ホリゾント(写真スタジオ)の明るいグレー、周囲のトレイは無彩色の暗いグレー
2. **色は意味にだけ使う** — キー=黄 / 再生ヘッド=赤 / 左=青 / 右=赤 / 中心=明るいグレー。UI のアクセント色は持たない。主ボタンは白
3. **罫線ゼロ** — 1px ボーダーで区切らない。6px の溝で切った角丸 12px のトレイで面を分ける。構造はトレイと余白で示す
4. **見出しラベルを置かない** — 「ボーン」「インスペクタ」「タイムライン」のような見出しは無し。内容そのもの(人体図、選択ボーン名、キー列)で分からせる
5. **数字が主役の場所を作る** — フレーム番号はトランスポート内でいちばん大きい(20px)。等幅・tabular
6. **動きは押した瞬間の 1 つだけ** — 押下は scale(0.96)、遷移は 150ms 以下の opacity/color。装飾アニメ無し。prefers-reduced-motion で 0 に

## トークン

| 用途 | 値 |
|---|---|
| 地 `--bg` | `#1c1c1c` |
| トレイ `--tray` | `#262626` |
| 浮き面(ステージ上の道具) `--float` | `rgba(28,28,28,0.92)` |
| 押し面 `--well` | `#1c1c1c` |
| 強調面 `--raised` | `#3a3a3a` |
| 分割線 `--rule`(トレイ内の縦仕切りのみ) | `#3a3a3a` |
| 文字 `--fg` / 補助 `--fg-2` / 薄 `--fg-3` | `#ececec` / `#a3a3a3` / `#6f6f6f` |
| 主ボタン | 背景 `#ececec`、文字 `#1c1c1c` |
| キー `--key` | `#ffd23f`(選択キーは白 + 黄の縁) |
| 再生ヘッド `--playhead` | `#ff4d3d` |
| 左 `--left` / 右 `--right` / 中心 `--center` | `#5aa0ff` / `#ff6a5c` / `#d6d6d6` |
| 軸 X / Y / Z | `#ff6a5c` / `#6fd36f` / `#5aa0ff` |
| ステージ | `linear-gradient(180deg, #cfcfcf 0%, #b9b9b9 52%, #8c8c8c 100%)`。three.js 側は背景を透明にして CSS のグラデーションを透かし、床は薄い接地影のみ。グリッドは出さない |

- 角丸: トレイ 12 / 浮きパネル 12〜16 / ボタン 8〜9 / 入力 8 / セグメント外 9・内 6(同心: 外 = 内 + パディング)
- 溝: 6px(画面の外周も 6px)
- 書体: UI = `'BIZ UDPGothic', sans-serif`(400/700)、数字 = `'Spline Sans Mono', monospace`(400/500、`font-variant-numeric: tabular-nums`)。Google Fonts を `web/index.html` で読む
- 文字サイズ: 本文 13 / 補助 12 / 選択ボーン名 17 太字 / フレーム番号 20

## レイアウト(1440×900 基準、可変)

- 外周 6px の地の上に、上バー 40px(名前・ファイル名と未保存の黄点・書き出しの白ボタン)、中段(左トレイ 250 / ステージ 可変 / 右トレイ 280)、下段トレイ 280px
- 左トレイ: タブ行(全身 / 手 / 表情 / ツリー)の下に人体図ピッカー。下端に左右中心の凡例
- ステージ: 左上にツール(移動/回転/IK | ミラー/オニオン)の浮きパネル、右上に視点(正面/側面/上 + フォーカス)、**下中央にトランスポートのカプセル**(先頭/1f/再生/1f/末尾 | フレーム番号 / 総数 | fps | ループ)、左下にアバター名とライセンス
- 右トレイ: 選択ボーン(色丸 + 名前 + ID)、回転 XYZ、「キーを打つ」(黄の主ボタン)+ 削除、補間セグメント、IK トグル、下端にミラー/コピー/ペースト/T ポーズ
- 下段: ツールバー行 44px(ドープシート/グラフ | 範囲選択/スナップ/キー間引き | トリム/ループ化/速度)、ラベル列 190px、ルーラー 24px、行 26px、トラック面は `#222222`、再生ヘッドは赤 2px + 上部に赤タグ

## 操作の手ざわり

- ボタンの押下は `scale(0.96)`。transition は `scale, background-color, color` を 120ms(ease-out)で、対象プロパティを必ず指定する
- フォーカスリングは白 2px の `outline`(罫線は使わない)
- `prefers-reduced-motion: reduce` では transition の時間を 0 にする
- アイコンは inline SVG(`currentColor`、線幅 2px)。絵文字は使わない

## 禁止

- 1px ボーダーで面を区切ること
- ティール・青緑のアクセント
- 見出しラベル
- ALL CAPS
- 中黒区切り(A · B)
- `transition: all`
- 装飾グラデーション(ステージのホリゾントは例外)
