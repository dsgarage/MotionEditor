# MotionEditor Web

VRM アバターのモーションをブラウザで編集するエディタ本体です(Vite + React + TypeScript + Three.js + three-vrm)。
仕様はリポジトリ直下の `docs/requirements.md` を参照してください。

## コマンド

Node.js 22 を想定しています。

```sh
npm ci          # 依存のインストール
npm run dev     # 開発サーバ(http://localhost:5173)
npm run build   # 型チェック + 本番ビルド(dist/)
npm test        # テスト(vitest)
npm run lint    # lint(oxlint)
```

## 使い方(現時点)

- 起動するとビューポートに簡易マネキンが出ます
- `.vrm`(VRM 0.x / 1.0)を画面にドラッグ&ドロップするか、上バーの「ファイル」で開くと表示が切り替わります
- ステージ左下にアバター名と改変・再配布の可否が出ます(改変禁止なら警告色)
- 左トレイの人体図でボーンを選ぶと、右トレイに現在フレームの回転(表示のみ)が出て、タイムラインの該当行が強調されます。ステージ右上の「正面 / 側面 / 上」で視点を切り替えます
- アバターを読み込んだあと `.vrma` をドロップするか、タイムラインの「サンプルを読む」でモーションを再生できます(アバター未読込だと「先にアバターを読み込んでください」と出ます)
- タイムライン(ドープシート)にボーンごとのキーが出ます。ルーラー・トラックのクリック / ドラッグでスクラブ、ホイールで横スクロール、Ctrl / ⌘ + ホイールでズーム、Shift + ホイールで縦スクロール、行ラベルのクリックでグループの展開 / 折りたたみ
- ショートカット: Space 再生・一時停止、← → 1 フレーム、Shift + ← → 10 フレーム、Home / End 先頭・末尾(入力欄にフォーカスがあるときは無効)
- VRMA は毎フレームサンプリングしてから、角度 0.5° / 位置 1mm / 表情 0.01 の誤差でキーを間引きます。角度のしきい値はタイムライン上部で変えられます
- ファイルはブラウザ内だけで処理し、外部へ送りません

## 構成

```
src/
  app/        レイアウト(上バー / 左右トレイ / ステージ)、トランスポート、ショートカット
  panels/     人体図ピッカーと選択ボーンの表示(インスペクタ)
  viewport/   Three.js のシーンと描画ループ、未読込時のマネキン
  avatar/     VRM 読み込みとライセンス情報の正規化
  motion/     内部モデル MotionDocument、VRMA 読込・ベイク・キー間引き・評価・アバターへの適用、再生ループ
  timeline/   Canvas 2D のドープシート(行の組み立てと描画)
  store/      zustand のエディタ状態
  ui/         ドロップ受付・ライセンス表示・共通ボタン・アイコン
  styles/     デザイントークン(tokens.css、docs/design.md 参照)とグローバル CSS
public/samples/  サンプル VRMA(pixiv/three-vrm、MIT。LICENSE.txt 参照)
```
